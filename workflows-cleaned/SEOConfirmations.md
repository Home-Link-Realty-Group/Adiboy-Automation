# SEO Priority Checklist — Home-Link Realty Group

Track progress on the top 10 SEO improvements to rank higher on Google.

---

## 🔍 Core Web Vitals & Page Speed

- [ ] Run PageSpeed Insights audit on homepage, GetOffer, top blog posts

- [ ] Identify LCP (Largest Contentful Paint), CLS (Cumulative Layout Shift), FID (First Input Delay) issues

- [ ] Minify CSS and defer non-critical JavaScript

- [ ] Lazy-load images (especially hero images)

- [ ] Reduce inline CSS where possible

- [ ] Target: All pages ≥90 PageSpeed score

---

## 📊 Strengthen Schema Markup

- [ ] Add Organization schema to all pages (name, logo, contact, social profiles)

- [ ] Add BreadcrumbList schema to blog articles

- [ ] Add FAQPage schema to FAQ page

- [ ] Add Article schema to all blog posts (author, publish date, featured image)

- [ ] Add LocalBusiness schema to city pages

- [ ] Validate with Schema.org validator

---

## 🏙️ City/Service Pages — Unique Content

- [ ] Audit Dallas, Houston, Fort Worth, etc. pages for content length (target: 1000+ words)

- [ ] Add neighborhood-specific content to each city page

- [ ] Include local comparable sales data or examples

- [ ] Add success stories/case studies for each city

- [ ] Add local service area map

- [ ] Ensure each city page has unique H1 and meta description

---

## 🔗 Internal Linking Structure

- [ ] Map content clusters (pillar pages + related articles)

- [ ] Add contextual links from blog posts to GetOffer page

- [ ] Add "Related Posts" section at end of each blog article

- [ ] Link city pages to relevant blog content (e.g., Dallas page → "Sell House Dallas" blog)

- [ ] Ensure no orphaned pages (every page linked from at least 1 other page)

- [ ] Use descriptive anchor text (avoid "click here")

---

## 🗺️ Sitemap & Robots.txt Optimization

- [ ] Verify sitemap.xml includes all priority pages

- [ ] Set priority tags (home: 1.0, GetOffer: 0.9, city pages: 0.8, blog: 0.7)

- [ ] Ensure robots.txt allows Googlebot to crawl all public pages

- [ ] Test sitemap in Google Search Console

- [ ] Submit updated sitemap to GSC

---

## 📝 Homepage & Page Titles / Meta Descriptions

- [ ] Update homepage title: "Cash Home Buyer [Service Areas] | Sell Your House As-Is Fast"

- [ ] Update homepage meta description (150-160 chars, include CTA)

- [ ] Audit all page titles for keyword relevance and uniqueness

- [ ] Audit all meta descriptions (target: 150-160 characters with CTA)

- [ ] Ensure titles/descriptions differ across all pages (no duplicates)

- [ ] Add city name to title/description for city-specific pages

---

## 📚 Pillar + Cluster Blog Content Strategy

- [ ] Create pillar page: "How to Sell a House Fast" (2000+ words)

- [ ] Create 5-10 cluster articles linking to pillar:

  - [ ] "Sell House As-Is"

  - [ ] "Sell Inherited House"

  - [ ] "Sell in Pre-Foreclosure"

  - [ ] "Sell in Divorce"

  - [ ] "Sell Rental Property"

- [ ] Interlink all cluster articles to pillar

- [ ] Add internal links from city pages to pillar/cluster

---

## ❓ FAQ Schema on Every Key Page

- [ ] Add FAQPage schema markup to FAQ page

- [ ] Add FAQ schema to GetOffer page (common questions)

- [ ] Add FAQ schema to city pages

- [ ] Ensure FAQ questions target long-tail keywords

- [ ] Validate schema with Google Rich Results Test

- [ ] Monitor SERP for FAQ snippets

---

## 🎯 Comparison & Resource Pages

- [ ] Expand "Blog Comparison" (cash vs realtor)

- [ ] Create "Cost of Selling Traditionally vs. Cash Sale"

- [ ] Create "Selling Timeline Comparison"

- [ ] Create "Guide to Probate & Inherited Properties"

- [ ] Create "What Happens During Foreclosure" guide

- [ ] Link all comparison pages to relevant city + blog content

---

## 📍 Local SEO Dominance

- [ ] Audit Google Business Profile for completeness:

  - [ ] Business name, address, phone correct

  - [ ] Add high-quality business photos (5-10+)

  - [ ] Add regular Google Posts (2x per week minimum)

  - [ ] Respond to all Q&A questions within 24 hours

  - [ ] Monitor and respond to reviews within 24 hours

- [ ] Get citations in local directories (Yelp, BBB, local directories)

- [ ] Encourage Google reviews via email/SMS to past clients

- [ ] Add "Sell Your House" CTA on GBP profile

- [ ] Ensure NAP (Name, Address, Phone) consistency across all directories

---

## 📊 Tracking & Measurement

- [ ] Set up Google Search Console (GSC) monitoring

- [ ] Track keyword rankings for target terms (use GSC or Ahrefs/SEMrush)

- [ ] Monitor organic traffic in Google Analytics

- [ ] Track conversion rate from organic traffic

- [ ] Review GSC reports monthly for:

  - [ ] Click-through rate (CTR)

  - [ ] Average position

  - [ ] Impressions

  - [ ] Coverage issues
